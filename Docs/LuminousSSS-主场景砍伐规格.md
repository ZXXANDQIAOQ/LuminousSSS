# LuminousSSS 主场景植被与砍伐规格（v0.12）

> 范围：`FarmScene`（登录后进入的农场主场景）。
> 目标：解决「界面太空旷」，并把「田地」变成**砍树开垦后才会暴露**的玩法内容。
> 引擎：团结引擎（Unity 2022.3 LTS 同源），UGUI + 2D Tilemap + Rigidbody2D 物理。

---

## 1. 结论先行

| 项 | 规格 |
|---|---|
| 田地初始状态 | **被 50 棵树覆盖**（梅花型密植，砍伐前看不见田地） |
| 砍伐方式 | 玩家走近按 **E**（PC）或点 HUD **砍伐按钮**（手机），每棵 **3 下**砍倒 |
| 砍倒后 | 树消失、原位置留**树桩**、碰撞去除 → **田地暴露**，可直接耕种 |
| 进度持久化 | 已砍树木写入 `PlayerPrefs`（`LuminousSSS.ChoppedTrees`），重进场景**不长回来** |
| 空旷问题 | 全图新增 **21 处**装饰（树 / 灌木 / 石头 / 花草），集中在木屋两侧空地 |

## 3. 田地种树规格（核心）

### 3.1 种植算法（梅花型）

```
范围：DirtRect 内缩 1 格（x 7..26, y 5..14）——四周留 1 格通道进田
步进：y 方向隔 2 格；x 方向隔 2 格，奇数 y 整行右移 1 格（错开成梅花）
树种：abs(x*31 + y*17) % 10 >= 6 → 松树（40%），否则阔叶树（60%）
```

| 参数 | 值 | 依据 |
|---|---|---|
| 每 2×2 格一棵 | 密度 25% | 再密砍伐疲劳、通道消失；再疏田地「秃」 |
| 树间通道 | **1.0 格** | 玩家半径 0.32（直径 0.64），通行余量 0.36 格 |
| 内缩 1 格 | 必须有 | 不内缩则边缘树把田堵死，玩家进不去 |
| 6:4 混栽 | 哈希决定 | 防条纹状纯色带；同坐标永远同树种（确定性） |

**实测（BFS 模拟，非目测）**：玩家可从田外一路走到田地中心 (16.5, 10.5)，
12506 个采样点验证通过；50 棵树无坐标重复、与土路/木屋零重叠。

### 3.2 单棵树规格

| 项 | 阔叶树 | 松树 |
|---|---|---|
| 素材 | `v2_nature_tree_broadleaf.png`（210×301） | `v2_nature_tree_pine.png`（136×305） |
| 世界尺寸 | 3.28 × 4.70 | 2.12 × 4.77 |
| 碰撞盒（宽×高） | 1.0 × 0.8 | 0.9 × 0.7 |
| 底部对齐 | groundY = 格心 y + 0.5 | 同左 |
| 排序 | `(MapH - groundY) × 10`（与玩家 YSort 同公式） | 同左 |
| 唯一 id | `tree_{x}_{y}`（种植格坐标） | 同左 |

### 3.3 砍伐规格

| 参数 | 值 | 依据 |
|---|---|---|
| `chopHits` | 3 | 1 下太轻无反馈；5 下以上开垦一片田太熬人（50 棵 × 3 = 150 击 ≈ 2~3 分钟纯砍伐） |
| `hitInterval` | 0.35 s | 防连点器一帧砍完；也够抖动动画（0.12 s）演完 |
| `interactRange` | 1.6 格 | 树碰撞盒外约 0.6 格可触及，不用贴死站位 |
| PC 按键 | `E` | 农场/生存游戏约定键；避开 WASD 与空格（空格常用于对话框） |
| 手机 | HUD 砍伐按钮 | 见 §5 |

**命中反馈（三下都有）**：
1. 树绕 z 轴 ±4° + x 压扁至 0.92，0.12 s 衰减回弹；
2. `sfx_chop.wav`（程序化合成：低频「咚」+ 木屑噪声「咔」，0.18 s）；
3. HUD 按钮保持高亮。

**砍倒反馈（第三下）**：树贴图换 `v2_nature_stump.png`（146×108，底部重新对齐
groundY）、`BoxCollider2D` 销毁（开垦地可通行）、`treeId` 写入 PlayerPrefs。

全部硬编码确定性坐标，重新生成场景结果不变；避开木屋本体、土路、已有物件。

| 区域 | 新增内容 |
|---|---|

加密后全图物件 25 → 46 处（不含田地 50 棵可砍树）。

## 5. HUD 砍伐按钮

| 项 | 值 | 依据 |
|---|---|---|
| 位置 | 右下角，锚 `(1,0)`，pivot `(1,0)` | 与左下摇杆对称；16:9 / 21:9 / 4:3 都贴角不跑位 |
| 尺寸 | 360 × 120 UI px | 远超点击区下限 88×88；与摇杆底圈 288 视觉平衡 |
| 底板 | `v2_ui_button_wood.png`，Image Type = **Sliced** | 九宫格 border 12（导入器已写）；任意宽高不糊 |
| PPU 补偿 | `pixelsPerUnitMultiplier = 1.5625` | 素材 64 vs Canvas 100，边框 1:1 显示 |
| 文字 | 「砍 伐」44px 暖白 + 深棕描边 2px | 与登录按钮同一 `Style`/`AddOutline` |
| 常态 | `interactable = false`（半透明） | 进场时没有可砍目标 |
| 点亮 | 有目标时 `ChopButtonDriver` 0.1s 内置 `interactable = true` | 看一眼就知道能不能砍 |

**持久监听坑（已规避）**：运行时 `onClick.AddListener` **不会被序列化**，
场景保存后丢失。构建器用 `UnityEventTools.RegisterPersistentListener` 写进
`m_OnClick.m_PersistentCalls`，指向 `ChopButtonDriver.OnClickChop`。

## 6. 持久化规格

| 项 | 值 |
|---|---|
| 键 | `LuminousSSS.ChoppedTrees` |
| 格式 | 逗号分隔的 treeId：`"tree_8_5,tree_10_5,..."` |
| 写入时机 | 第三下砍倒时（`PlayerPrefs.Save()` 立即落盘） |
| 读取时机 | `TreeChop.Awake` —— 已砍则直接进入砍倒态（不播动画、不发音） |
| 上限保护 | `MarkChopped` 先查重再追加，不会无限增长 |

> 设计取舍：不做「树重新长回来」的计时器 —— 开垦玩法里玩家对田地的
> 期待是「我砍了就是我的」，长回来反而是负面反馈。

## 8. 验证情况（沙箱无引擎，如实说明）

| 验证项 | 方法 | 结果 |
|---|---|---|
| C# 语法 | Roslyn 逐文件解析（C# 9） | 6 个文件 **0 错误** |
| 种植算法 | Python 复刻同坐标逻辑 | 50 棵（30 阔 + 20 松）、无重复、零重叠 |
| 田地连通性 | BFS（12506 采样点） | 田外 → 田中心可达 |
| 树间距 | 全对最近邻 | 2.0 格，通道 1.0 格 > 玩家直径 0.64 |
| GUID 冲突 | 全库 359 个 meta | 0 冲突 |
| 音频回归 | 重新生成既有 3 个音频 | 与仓库版本**逐字节一致** |
| ⚠️ 引擎内编译/运行 | 沙箱无团结引擎 | **未验证**，需在编辑器里跑一次确认 |

**引擎内验收步骤**（用户侧）：
1. 打开工程 → 等自动导入完成（`AutoBuildScenes` 检测到 `FarmScene.scene` 存在则不动，
   要么删掉该文件让它自动重建，要么手动 `Tools/LuminousSSS/2. 生成游戏场景`）；
2. 点播放 → 登录 → 开始游戏 → 应看到**田地全被树覆盖**；
3. 走到任意树旁按 E（或点右下砍伐按钮）→ 树抖 3 下变树桩，HUD 按钮变灰；
4. 砍掉一片后退出重进 → 砍过的位置保持树桩，**不长回来**。
