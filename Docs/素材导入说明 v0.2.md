## 三、做了哪些处理

### 1. 黑底 → 透明

文档要求「精灵素材统一用纯黑背景，导入时做透明处理」。脚本按 `max(R,G,B) ≤ 30` 判定纯黑并置为透明，同时把透明区域的 RGB 清零（避免边缘发灰）。

实测原始黑底亮度集中在 0–10，与前景（≥40）分得很开，阈值 30 安全。

### 2. 切分

- **瓦片**：合集是规整的 16 列 × 8 行网格，每格 181×181 px（2896 = 16×181，1448 = 8×181，正好整除）。按格等分切出 128 张，**不做裁剪**——瓦片必须等大且边缘完整才能无缝平铺。
- **其余元素**：用连通域（`scipy.ndimage.label`）找出互不相连的块，再按「行→列」排序。这样做比按投影切更准，能正确处理同一行里位置错开的元素。
- **行走帧**：连通域会把帧之间的箭头单独切出来，按「宽扁比 ≥ 2.5 且高 ≤ 60」过滤掉，最终得到干净的 4 方向 × 6 帧。
- **UI 标题栏 + 对话框**：这两块边框相接，连通域会认成一块。脚本按 y=135 处拆开（上方 715×135 是标题栏，下方是对话框面板）。

### 3. 尺寸归一化

源素材的瓦片是 181×181 px，直接进 Unity 会让「1 tile ≠ 1 世界单位」。脚本按 **1 tile = 64 px** 统一缩放（比例 = 64/181 ≈ 0.354），理由是：

- 相机 `orthographicSize = 10` → 视野高 20 单位；1080p 下 1 单位 ≈ 54 px
- 64 px 的瓦片显示约 54 px，接近 1:1，既清晰又不浪费显存

**对应 Unity 导入 PPU = 64**（见下）。这样 V2 素材与 v0.1 素材在世界尺寸上完全一致（都是 1 tile = 1 单位）。

立绘不按瓦片比例（它显示在登录界面，尺寸独立），单独缩到高 1024。UI 素材按 0.5 缩放。

## 四、Unity 里怎么用

### 导入设置（已自动处理）

`Assets/Editor/PixelArtImporter.cs` 已改成**按路径分档设 PPU**：

| 路径 | PPU | 说明 |
|---|---|---|
| `Assets/Art/`（v0.1 素材） | 32 | 1 tile = 32 px |
| `Assets/Art/V2/`（本批素材） | 64 | 1 tile = 64 px |

其余设置两档相同：Sprite 类型、`Point` 过滤、无压缩、无 mipmap、FullRect 网格、`alphaIsTransparency`。

新素材放进工程后，Unity 首次导入就会按上面的规则设置；如果发现没生效，跑菜单 **`Tools → LuminousSSS → 1. 重新导入像素资源`**。

### 瓦片

128 张瓦片对应 16×8 的原始排布，按内容分布：

- 绿草地、带花草的深色草地
- 黄褐色耕地泥土、压实土路
- 灰色石墙、木栅栏
- 蓝色水面、沙地

同一种地形有多个格子（AI 生成时每格有细微纹理差异），可以当 auto-tile 的变体用。

### 九宫格（建议手动设）

`v2_ui_dialog_panel`、`v2_ui_button_wood`、`v2_ui_button_selected`、`v2_ui_title_bar` 这类有边框的 UI，建议在 Sprite Editor 里设 **Border**（九宫格），再用 `Image.Type = Sliced`，拉伸时边框才不会变形。

### 其他

- 建筑/树/石的 Pivot 建议设为**底部中心**，方便对齐 Tilemap。
- 排序层级参考文档：草地 0、树石 1、建筑 3、玩家 5。

## 五、重新生成

素材全部由脚本生成，可随时重跑：

```bash
# 需要 Pillow + numpy + scipy
python Tools/import_v2_assets.py --src <素材目录> --preview <可选预览输出目录>
```

调色板 / 缩放比例等常量都在 `Tools/import_v2_assets.py` 文件顶部。
