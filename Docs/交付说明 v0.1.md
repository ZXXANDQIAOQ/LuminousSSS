## 一、三步跑起来

1. **用团结引擎 Hub 打开工程**：`E:\Document\GameCode\LuminousSSS\LuminousSSS`
   （编辑器 `2022.3.62t16` / Tuanjie `1.10.4`；首次打开会导入资源，等右下角进度条走完）
2. **菜单栏 → `Tools` → `LuminousSSS` → 「一键生成（资源 + 场景）」**
3. 生成完会自动打开 `LoginScene`，**点 ▶ 播放**

> **为什么要在编辑器里点菜单？** 本机团结引擎的命令行模式（`-batchmode`）会卡在
> `Application.AssetDatabase Initial Refresh Start` 不动，GUI 加 `-quit` 又会在资源导入完成前退出。
> 所以场景生成必须由你在编辑器里点一下，这是本机的已知限制，不是脚本的问题。

## 四、几个技术约定

- **1 tile = 32 px = 1 世界单位**，所有像素贴图按 `PPU=32`、`FilterMode=Point`、无压缩导入
  （由 `PixelArtImporter` 自动应用，不用手动改 Inspector）。
- **色彩空间保持 Linear，没有改 Gamma。** 之前提过要改，核实后决定不改：URP 对 Gamma
  色彩空间支持有限（部分效果不生效并会在 Console 报警告）。像素锐利度靠 `Point` 过滤 +
  PPU 对齐保证，与色彩空间无关。
- **屏幕方向已锁定横屏 Landscape Left**（原为自动旋转）。
- 地图 40×24 tiles；木屋底部落在 y=14，土路两列从木屋门口通到地图底部出口；玩家出生在
  土路 (29, 13)，面向下方。

## 五、已知限制 / 下次可改的点

1. **中文靠动态系统字体**：`UIFontFixer` 在运行时用 `Font.CreateDynamicFontFromOSFont` 挂
   「微软雅黑」等系统字体。好处是不用生成 TMP 字体图集；代价是**打包到设备时目标设备必须有
   这些字体**（Android 一般有 `Noto Sans CJK SC`）。要做正式版建议换成 TMP + 静态字体图集。
2. **角色立绘是白底 JPEG 抠的**：边缘已做腐蚀处理，放大看仍可能有一两像素的毛边。
   文档 3.5 要求的「正式版透明背景切片」建议后续拿原始透明素材替换。
3. **场景素材是按参考图摆的近似版**：土黄空地是矩形（参考图里边缘更自然），
   地面与草地之间没有做过渡 tile（需 autotile / Rule Tile 才能做）。
4. **小像素人比较简化**：只有站立 idle，没有四方向行走（文档里本就在「本次不做」列表）。
5. **美术全部由程序化生成**：风格统一、随时可改。想调整颜色/尺寸改 `Tools/gen_art.py`
   里的调色板与尺寸常量，重跑脚本即可；场景布局改 `GameSceneBuilder.cs` 里的坐标表。
