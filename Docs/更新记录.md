## v0.7 — 2026-10-15 · 修复女巫立绘在登录界面的显示体量

**v0.6 把立绘容器统一成 260×512 后，Q 版小像素素材被放大到和人形立绘一样大。**

- **现象**：女巫素材 `v2_witch_idle` 只有 54×101，`preserveAspect` 让它「撑满」容器 →
  实际显示 **260×486**；而农夫（397×1024）显示 199×512。女巫比人形立绘还宽，
  且是 4.8 倍放大的大颗粒像素块，两者并列时体量与风格都割裂。
- **修复**：`CharacterInfo` 新增 `displayScale`（默认 1，只影响登录界面展示，不动素材）；
  `CharacterPreview.SetFrames(frames, displayScale)` 改容器 `localScale`——
  sprite 仍走 `preserveAspect`，所以像素比例不变、不会被拉伸；
  `CharacterSelector.Refresh` 两条分支（preview / portraitImage）都传这个值，
  切换角色时自动应用与还原。浮动幅度同步乘 `displayScale`，缩放后观感一致。
- **女巫取值 0.7** → 实际显示约 **182×340**（Q 版小人略矮于人手立绘、宽度相近）。
  嫌高或矮只改 `GameSceneBuilder` 里 `displayScale = 0.7f` 这一个数。
- 影响面：只改登录界面立绘的显示大小；场景内小人（`worldSprite`）、FarmScene、音频、
  设置弹窗、九宫格与素材均未改动。
- 验证：Roslyn 解析 4 个改动文件 0 语法错误；用 Python 复算 `preserveAspect` 的
  contain 结果（见下表），确认所有角色显示尺寸符合预期。
  **未在团结引擎内编译运行**，请重新执行 `Tools/LuminousSSS/一键生成（资源 + 场景）` 后肉眼确认。

| 角色 | 素材尺寸 | 修改前显示 | 修改后显示 |
|---|---|---|---|
| 农夫 001 | 397×1024 | 199×512 | 199×512（不变） |
| 雨女 002 | 533×1024 | 260×499 | 260×499（不变） |
| 冒险者 003 | 446×1024 | 223×512 | 223×512（不变） |
| 女巫 004 | 54×101 | **260×486** | **182×340** |

## v0.6 — 2026-10-15 · 登录界面重做

**修正版式颠倒 + 接入项目自有的 V2 像素 UI 素材。** 此前登录界面全是纯色直角块拼的，而且整体镜像。

- **修掉版式颠倒**：`CreateUI` 用的是左上角锚点，但布局参数按「距屏幕底部」写的 ——
  标题跑到屏幕最底（压在 TopBar 色带上）、开始/设置按钮跑到最顶、角色名夹在按钮下面。
  新布局：标题木牌 y120 / 主面板 820×840 居中 / 立绘 y510 / 切换按钮 y510 / 名字 y845 / 按钮行 y960。
- **接入 V2 像素 UI 素材**（此前一个都没引用）：羊皮纸面板做容器、木纹九宫格做按钮与标题牌、
  齿轮图标、像素箭头；立绘换 V2 版（高 1024）按 1:2 整数缩放显示，像素不糊。
- **按钮补齐四态**：Normal / Highlighted / Pressed / Disabled，fade 0.08s。
- **九宫格**：`PixelArtImporter` 新增 `SpriteBorders` 表，素材导入时自动写入边界；
  素材 PPU=64 而 Canvas 为 100，统一用 `pixelsPerUnitMultiplier = 100/64` 抵消，边框按原始像素 1:1 显示。
- **CanvasScaler Match 0.5 → 1.0**：原值在 21:9 下虚拟高只剩 935，底部按钮会被裁掉。
- **字号阶梯收敛**：96/60/56/44/40 → 56/48/44/36（全部 4 的整数倍）；按钮高 96 → 104。
- **素材**：修复两张木纹按钮上的 AI 残渣（深棕虚线框 / 「I+I」形残字）；
  新增背景、纵向面板、像素箭头、立绘投影共 5 张（全部由 `Tools/gen_*.py` 程序化生成，可重跑）；
  **弃用 `v2_ui_title_bar`** —— 图内印着伪英文「STARD SVENT」，影射 Stardew Valley，有版权风险。
- 新增 `Docs/LuminousSSS-UI规格 登录界面改版.md`（尺寸表 / 九宫格参数 / 状态矩阵 / 落地配置）。
- 验证：Roslyn 解析 3 个改动文件 0 语法错误；生成脚本重跑，5 张素材输出与原图 md5 一致。
  **未在团结引擎内编译运行**，合并后请先执行 `Tools/LuminousSSS/一键生成（资源 + 场景）`。
