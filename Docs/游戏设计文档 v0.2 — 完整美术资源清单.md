## 一、项目基本信息

| 项目 | 说明 |
|---|---|
| 游戏类型 | 2D 俯视角像素风 / 开放探索 / 建造经营 |
| 引擎 | 团结引擎 2D (URP) |
| 渲染管线 | URP + 2D Renderer |
| 视角 | 正俯视 (Top-Down Orthographic) |
| 屏幕方向 | 横屏 Landscape（Landscape Left） |
| 分辨率 | 1920×1080 或 1280×720 |
| 美术参考 | 星露谷物语 / 牧场物语（Story of Seasons） |

## 二、美术风格规范（所有素材必须遵守）

- **像素风格**：16-bit SNES/GBA 硬边像素，像素颗粒清晰，无抗锯齿平滑渐变
- **视角**：正俯视（top-down orthographic），禁止斜 45° 等距视角
- **色彩**：土黄色空地为主 + 深绿草地边缘，Q 版圆润树木/石头/树桩/木屋
- **地面**：土黄色（`#D4A04A` 附近）为可建造/耕地，深绿色（`#4A8C3A` 附近）为草地
- **树木**：Q 版圆润阔叶树 + 深绿松树两种
- **角色**：Q 版大头小身比例（chibi），正面站立 idle 姿态
- **背景**：精灵素材统一用纯黑背景（`#000000`），导入 Unity 时做透明处理

## 四、界面设计

### 4.1 界面一：登录 / 角色选择界面

布局（横屏 16:9）：

```
┌─────────────────────────────────────────────┐
│                                             │
│   [游戏标题 LOGO — 占位]                      │
│                                             │
│        ┌──────┐                             │
│        │ 角色  │      ◀  ▶                  │
│        │ 立绘  │   （左右切换角色）           │
│        │ 正面图 │                             │
│        └──────┘                             │
│                                             │
│         角色名称：【农夫】                    │
│                                             │
│      [ 开 始 游 戏 ]  [ 设 置 ]              │
│                                             │
└─────────────────────────────────────────────┘
```

交互逻辑：

- 点 ◀ ▶ 切换角色，立绘和名称联动更新
- 点「开始游戏」→ 保存选择的角色 ID（PlayerPrefs）→ 跳转到主场景
- 点「设置」→ 暂未实现，预留入口按钮

使用素材：CHR-001 / CHR-002 / CHR-003 角色立绘 + UI-001 按钮

## 五、素材导入 Unity 注意事项

- **瓦片集切图**：TILE-001 在 Unity Sprite Editor 中按格子切分，每格 32×32 或 16×16（根据游戏设计定）
- **精灵切分**：所有黑底素材导入时 Texture Type 设为 Sprite，黑底通过 Shader 或导入设置做透明处理（或在 Unity 中用 Sprite Editor 抠图）
- **像素完美**：Project Settings → Quality → Pixel Perfect 开启，相机加 Pixel Perfect 组件
- **Pivot 点**：建筑和树的 Pivot 设在底部中心（脚下位置），方便对齐 Tilemap
- **排序层级**：草地 Order in Layer = 0，树木/石头 = 1，玩家 = 5，建筑 = 3
