# LuminousSSS 小洋楼室内规格（v0.14）

> 范围：`House1FScene` / `House2FScene`（农场木屋 → 靠近门口按交互进入）。
> 目标：把「家具展销厅」改成**有功能分区、有生活痕迹**的室内。
> 结构：26 × 14 格，1 格 = 64 素材像素（PPU 64），后墙 2 行（y12 墙纸 / y13 墙顶木）。

---

## 1. 结论先行

| 项 | 规格 |
|---|---|
| 一层分区 | 左侧客厅（木地板 x1..13）+ 中间门厅（x13）+ 右侧餐厨（瓷砖 x14..24） |
| 二层分区 | 左侧卧室（x1..12）+ 右侧书房（x13..21）+ 右上楼梯 |
| 材质分区 | 餐厨铺 `v2_in_floor_tile`，其余木地板（两种板纹按坐标哈希混铺） |
| 家具总数 | 一层 27 件 / 二层 15 件（原 15 / 13） |
| 相机 | `orthographicSize = 7`（视野 14×24.9 格，几乎全览屋内），跟随预判收至 1.0 格 |

## 2. 三条硬规则（改布局必须遵守）

### 2.1 贴后墙家具：按「顶部贴墙顶」反算 groundY

```
groundY = 14 - 精灵高度（格）
```

**原实现是错的一半**：所有贴墙家具一律 `groundY = 12`（墙脚），3~5 格高的家具顶部会到 15~17，
而相机视野只到 **y 13.5** —— 二楼的床（5 格）、书架（3 格）、衣柜（3.5 格）顶部全被裁掉。
现在按高度反算：床 9（顶 13.5）、衣柜 10.5、书架/壁炉/楼梯 11、台面/书桌 12。

### 2.2 墙饰：`groundY = 12` 起，order 固定 40

**原实现把挂饰的 groundY 写成 `RoomH`（14）** —— 精灵底部在墙顶之上，整块画在房间外，
**从来没在画面里出现过**（这就是"墙上空荡荡"的直接原因）。改为底部压在墙脚 y=12：
- 窗（2 格高）→ groundY 12，占 y12..14
- 画 / 钟（1.5 格高）→ groundY 12.5，占 y12.5..14
- `orderOverride = 40`：高于贴墙家具的 30，避免位置微重叠时被吞

### 2.3 地毯：`orderOverride = -50`

地毯的 groundY 很小（2~3），按 Y 排序公式 `(14 - groundY) × 10` 会得到 110~120，
**比所有家具都高** —— 原实现里餐桌地毯会把椅子整排盖住。
固定为 -50：地板（-100）之上、所有家具之下。

## 7. 后续可扩展

- 厨房吊柜 / 灶台：现有素材没有，需要新画（`Tools/gen_house_interior.py` 里加）
- 家具交互（坐下、开衣柜、睡觉过夜）：需要 IInteractable 的第二种实现
- 室内光照（壁炉暖光叠加）：需要 2D Light，工程当前是 URP 2D，可加 Light2D
- 房间分隔：26×14 已经是单间上限，做多房间要把房间拆小、相机跟随重调
