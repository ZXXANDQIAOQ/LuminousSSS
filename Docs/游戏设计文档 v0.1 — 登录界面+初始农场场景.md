## 一、项目基本信息

| 项目 | 说明 |
|---|---|
| 游戏类型 | 2D 俯视角像素风 / 开放探索 / 建造经营 |
| 引擎 | 团结引擎 2D (URP) |
| 渲染管线 | URP + 2D Renderer |
| 视角 | 正俯视 (Top-Down Orthographic) |
| 屏幕方向 | 横屏 Landscape（Landscape Left） |
| 分辨率 | 1920×1080 或 1280×720 |
| 美术参考 | 星露谷物语 / 牧场物语（Story of Seasons） |
| 当前范围 | 仅实现「登录角色选择界面」+「初始农场场景」两个界面 |

## 二、美术风格规范（所有素材必须遵守）

1. 像素风格：16-bit SNES/GBA 硬边像素，像素颗粒清晰，无抗锯齿平滑渐变
2. 视角：正俯视（top-down orthographic），禁止斜 45° 等距视角
3. 色彩：土黄色空地为主 + 深绿草地边缘，Q 版圆润树木/石头/树桩/木屋
4. 地面：土黄色（#D4A04A 附近）为可建造/耕地，深绿色（#4A8C3A 附近）为草地
5. 树木：Q 版圆润阔叶树 + 深绿松树两种
6. 角色：Q 版大头小身比例（chibi），正面站立 idle 姿态

### 3.4 交互逻辑

- 点 ◀ ▶ 切换角色，立绘和名称联动更新
- 点「开始游戏」→ 保存选择的角色 ID（PlayerPrefs）→ 跳转到主场景
- 点「设置」→ 暂未实现，预留入口按钮

### 3.5 技术备注

- 角色立绘当前为白底 PNG，正式版本需做透明背景切片
- 角色选择结果通过 PlayerPrefs / 单例传递到主场景

## 四、界面二：初始农场场景（主场景）

### 4.1 功能目标

玩家进入游戏后的第一个可操作场景，即主角出生点。中央空地用于后续建造房子和功能建筑。

### 4.2 场景参考素材

场景整体参考图（已生成，作为 Tilemap 布局参考）：https://aka.doubaocdn.com/s/dIOgW8thWG

本地副本：`Docs/Refs/scene_farm_reference.jpg`

### 4.3 场景元素清单

| 区域 | 元素 | 交互 |
|---|---|---|
| 右上角 | 小木屋（红屋顶、石烟囱、木质门廊、邮箱） | 暂不可进入，后续做室内场景 |
| 中央大块区域 | 土黄色空地（约占画面 60%） | 玩家建造/耕种核心区 |
| 左侧边缘 | 阔叶树×4、灰石头×3、树桩×3、小杂草 | 可砍树 / 可挖矿 / 可捡杂草 |
| 右侧边缘 | 松树×3、树桩×2 | 可砍树 |
| 底部边缘 | 横放木头×1、石头×2、树桩×3、小草 | 可采集 |
| 顶部边界 | 石墙 + 一排灌木 | 地图边界，不可通行 |
| 土路 | 从木屋门口 → 向下 → 底部出口 | 导航路径 |

### 4.4 玩家初始位置

- 出生点：木屋门口正前方的土路上
- 初始朝向：面向下方（场景出口方向）
- 移动控制：WASD / 方向键，角色为正俯视小人

### 4.5 场景边界

- 上：石墙阻挡
- 左/右/下：树木和自然元素构成边界，不可穿越
- 底部土路出口：后续连接小镇场景（本期不实现）

### 4.6 相机

- 正交相机（Orthographic）
- 跟随玩家移动，平滑跟随
- 初始视野覆盖整个农场区域（约 16:9）

## 五、当前版本范围

**已包含（本次实施）**

- 登录界面 UI 框架（标题区、角色立绘显示、左右切换按钮、开始按钮）
- 3 个占位角色可切换
- 农场场景静态展示（按参考图布局摆放元素）
- 场景边界设置（不可走出地图）

**待实现（后续补充，本次不做）**

- 角色四方向行走动画
- 玩家移动控制脚本
- 砍树 / 挖矿 / 采集交互
- 建造系统入口
- 木屋室内场景
- 底部出口连接小镇
- 角色自定义（发型/衣服颜色）

## 六、实施优先级

1. 先搭登录界面：UI 布局 + 角色切换逻辑 + 场景跳转
2. 再搭农场场景：按参考图摆 Tilemap + 放置木屋 + 摆树木石头
3. 最后连玩家：把占位角色放到木屋门口土路上，能在空地上移动（本期可选）
