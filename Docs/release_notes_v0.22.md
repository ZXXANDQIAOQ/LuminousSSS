## 本版内容

### 铁匠铺

- 集市铁匠铺落了实体布景：**铁砧** 与 **锻炉**，铁匠老王持锤站在砧后，锤头落点与火花位置对齐
- 打铁演出化：锤击火花迸溅、命中闪光、冲击环、烟尘、入神状态脉冲，配 7 种程序化合成音效
- 铁匠铺内可直接购买铁矿石

### 角色

- 四个可玩角色：女巫「烁」、银骑士、森之猎手、炼金术士
- 「烁」保留原始立绘（54×101，逐字节未改），新增四方向 6 帧行走动画（只位移靴子像素）
- 修复：角色悬空 3px、移动时无动作、移速过快（统一为 2.8 格/秒）

### 其它修复

- 震动相机变量与平滑系数命名冲突导致编译失败（CS0136）
- 打铁界面退出后画面卡死（遮罩残留）
- 建筑碰撞盒只挡底部导致的穿模「走进贴图里」
- 钓鱼等待期可重复交互、咬钩窗口过短

## 安装

```bash
adb install -r LuminousSSS_v0.22_arm64_dev.apk
```

或在手机上允许「安装未知来源应用」后直接点开 APK。

## 已知限制

- 只有正面行走姿势，**向上走时会看到正脸**（原画没有背面帧，补帧需要动形象）
- 首次启动需要解压资源，冷启动约 5~10 秒
