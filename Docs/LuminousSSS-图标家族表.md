## 4. 视觉权重配平（判定方法）

把全部图标排成网格，**眯眼看不应有任何一个「跳出来」**。

本批的配平做法：

| 形状类型 | 补偿 |
|---|---|
| 方形 / 团块（木板、石头堆） | 按画布 72% 铺 |
| 圆形 / 菱形（金币、宝石） | 视觉面积天然偏小 → **外扩 6%** |
| 细长条形（鱼、斧、镐） | 按**长边**对齐，不按面积 |
| 竖直高瘦（种子袋、蘑菇） | 按**高度**对齐到 82% |

### 可辨识性四测（做不过就重做，不是「再调调」）

1. **100% 测试**：缩到 64px，距屏幕 50cm，0.5 秒内能否认出。
2. **75% 测试**：缩到 48px 仍能认出。
3. **涂黑剪影测试**：填纯黑后，剪影能否与同族其他图标区分。
   本批需要重点核对的两对：`seed_carrot` / `seed_tomato` / `seed_radish`（形状相同，**仅靠颜色区分**）。
   → 剪影测试**必然不过**，因此这三个**必须在颜色之外再加一层区分**（目前靠中心标记的色调差）。
   若你的背包会是灰度或被色盲模式覆盖，需要补形状差异（胡萝卜标记改成尖锥、番茄改成圆、萝卜改成水滴）。
4. **灰度测试**：转灰度后仅靠明度能否区分。本批 `coin_gold` 与 `fish_gold` 明度接近，同屏出现时注意。

## 5. 命名规范

沿用项目既有规范（**不改**，因为仓库里上百个文件已经按这个来了）：

```
v2_<类别>_<名称>.png
```

| 段位 | 取值 | 示例 |
|---|---|---|
| 前缀 | 固定 `v2` | `v2` |
| 类别 | `ui` / `item` / `nature` / `building` / `fx` / `character` / `tile` / `portrait` | `item` |
| 名称 | 小写英文，下划线分隔 | `seed_carrot` |

**类别取自固定清单，不允许临时新增**；新类别要先更新本文档再使用。

> 与 Skill 默认规范（`icon_<分类>_<名称>_<尺寸>_<状态>@vN.png`）的差异：
> 项目已用 `v2_` 前缀、无尺寸段（因为同族只有一档）、无版本段（靠 git 管版本）。
> **一致性优先于规范教条** —— 一套仓库里两种命名比两种都不规范更糟。
> 如果以后道具图标要出多档尺寸，再补 `_<尺寸>` 段。

## 6. 状态变体

| 状态 | 实现方式 | 是否需要独立图 |
|---|---|---|
| 常态 | 基准图 | — |
| 高亮 / 悬停 | 格子换 `v2_ui_slot_selected` | ❌ 图标本体不动 |
| 选中 | 同上 + 图标整体上浮 4px | ❌ |
| 禁用 / 锁定 | 灰度着色 + `alpha 0.5` | ❌ 引擎内 tint |
| 已拥有 / 已装备 | 角标叠加图（`v2_ui_icon_check`，**未出，待确认是否需要**） | ⚠️ 待定 |
| 品质色（白蓝紫金橙） | 品质底框独立资源 + 图标本体共用 | ⚠️ 需求清单未提品质系统，**暂不出** |

> **染色需求**：如果以后要按品质给图标本体染色，**必须额外交付纯白版本**（靠 `Sprite.color` 染色）。
> 全彩图标直接染色会得到脏色。本批未出纯白版 —— 需求清单里没有品质系统，出了是浪费。
> 项目若确定要做品质系统，说一声我补 13 张纯白版，成本很低（脚本改一个参数）。
