# LuminousSSS UI 规格（本轮新增部分）

> 目标引擎：团结引擎 2022.3（UGUI）｜设计分辨率：1920×1080 横屏｜PPU：`Assets/Art/V2/` = 64
> 基线：`采集/素材需求清单.md` v0.7（`c7d1211`）｜本文档描述**本轮新增的 UI 素材**及其规格
> 已有登录界面规格见 `Docs/LuminousSSS-UI规格 登录界面改版.md`，本文不覆盖它的任何已确认项

---

## 0. 结论先行

三条：

1. **本轮补齐了需求清单第六节 UI-01 ~ UI-11 的全部缺口**，共 22 张，全部程序化生成、可重跑、零 AI 残字风险。
2. **顺手发现一个需求清单没记的问题**：现有 UI / 道具 / 行走帧素材存在大面积**非硬边残留**（半透明像素），实测 UI 平均 **12.8%**、最高 **69.3%**。像素游戏开 Point 过滤后，这些像素会变成一圈灰黑毛边。本批新素材该项为 **0.0%**。
3. **`v2_ui_heart` / `v2_ui_stamina_bar` / `v2_ui_slot_item` 三张建议直接换成本批同功能新品**，否则新老素材并排会风格割裂。

## 1. 实测依据（不是估计，是跑出来的）

| 素材组 | 数量 | 半透明像素平均占比 | 最高 | 超标文件（>2%） |
|---|---|---|---|---|
| **本批新增 UI** | 22 | **0.0%** | 0.0% | 0 |
| **本批新增 道具** | 13 | **0.0%** | 0.0% | 0 |
| **本批新增 特效** | 15 | **0.0%** | 0.0% | 0 |
| 现有 UI | 17 | 12.8% | 69.3%（`v2_ui_portrait_shadow`） | 12 / 17 |
| 现有 道具 | 15 | 15.5% | 35.3% | 15 / 15 |
| 现有 行走帧 | 31 | 17.2% | 24.3% | 24 / 31 |
| 现有 自然元素 | 13 | 17.1% | 48.5% | 13 / 13 |
| 现有 立绘 | 3 | 3.8% | 4.9% | 3 / 3 |

> 判定方法：`alpha` 通道中 `0 < a < 255` 的像素占比。像素风素材应接近 0 —— 它由 `Tools/import_v2_assets.py` 的
> 黑底抠图（`max(RGB) ≤ 30` 置透明）产生，阈值边缘必然留下 alpha 渐变。
> 复核脚本：`Tools/verify_hardedge.py`。

**为什么这条值得单独修**：项目贴图导入设置是 `Filter Mode = Point`、`Compression = None`。
毛边在 Point 下不会被平滑掉，而是变成硬邦邦的一圈脏边；素材一旦进图集（Atlas）后，
透明区被裁掉时那圈像素还会跟着被算进图集面积。

## 2. 版式四件套

### 2.1 栅格与安全区（沿用已确认值）

| 项 | 值 | 依据 |
|---|---|---|
| 设计分辨率 | 1920×1080 | 项目已确认 |
| Canvas Scaler Match | **1.0（按高度）** | 21:9 下 Match=0.5 会把底部按钮裁掉，已有结论 |
| 安全区余量 | 左右各 550px（28.6% 屏宽） | 覆盖 4:3 ~ 21:9 |
| HUD 边距 | 上/左/右 **48px**，下 **64px** | 48 是 4 的整数倍；底部抬高留出安全区 |
| 对齐基准 | 2 或 4 的整数倍 | 避免半像素模糊与缝隙 |

### 2.2 层级（五层，本轮补齐后三层有素材了）

| 层 | 内容 | 本批素材 | 遮罩 / 拦截 |
|---|---|---|---|
| 0 背景 | 场景 / 登录底图 | — | 不拦截 |
| 1 场景内容 | 玩家 / NPC / 物件 | — | 不拦截 |
| 2 HUD | 血量、体力、金币、日期 | `heart_*` `stamina_*` `currency_plate` | 穿透（不拦截点击） |
| 3 面板 | 背包、tooltip、对话 | `panel_inventory` `tooltip_panel` `dialog_bubble` | 遮罩：模态时拦截下层 |
| 4 弹窗 / 转场 | 设置、确认框、加载 | `transition` `load_*` `switch_*` | 全屏拦截 |

> 规则：**层 3 的面板默认不拦截点击走空**，只有标记为模态时才挂全屏透明 `Image` + `raycastTarget = true`。
> 层 4 的 `transition` 恒为全屏拦截。

### 2.3 字号阶梯（沿用，未改动）

| 档位 | 字号 | 用例 |
|---|---|---|
| Display | 56 | 标题 |
| Title | 48 | 弹窗标题 |
| Emphasis | 44 | 角色名 / 数值强调 |
| Body | 36 | 按钮文字、设置项 |

全部为 4 的整数倍。**新增 UI 素材的文字一律引擎内渲染，图内不含任何文字。**

### 2.4 点击区

| 元素 | 视觉尺寸 | 判定 |
|---|---|---|
| 主/次按钮 | 320×104 | ✅ ≥ 88×88 |
| `v2_ui_switch_on/off` | 80×40 | ⚠️ 高度不足，**点击区需外扩到 ≥ 88×88**（Image 尺寸 80×40，另加透明 `Image` 或 `Button` 撑到 88×88） |
| `v2_ui_slot_empty` | 96×96 | ✅ |
| 关闭按钮 | 300×100 | ✅ |

> 这条是本轮新增的注意项：**视觉尺寸与点击区分离**，小图标按钮必须补透明点击区，否则触屏点不中。

| Unity / 团结引擎 | **左 / 下 / 右 / 上** ← 本项目 |
| Godot 4 · Unreal | 左 / 上 / 右 / 下 |
| Cocos Creator | 左 / 右 / 上 / 下 |

### 4.1 PPU 补偿（沿用项目已有做法，漏了边框会粗 1.56 倍）

素材 PPU = 64，Canvas `referencePixelsPerUnit` = 100：

```csharp
img.type = Image.Type.Sliced;
img.pixelsPerUnitMultiplier = 100f / 64f;   // = 1.5625
```

> 本项目 `Assets/Editor/PixelArtImporter.cs` 已有 `SpriteBorders` 表，本轮新增素材**需要把上表的
> 9 个九宫格素材补进这张表**，否则美术重导出素材后边界会丢。补表代码见 `03-落地清单`。

- 按钮 `fadeDuration = 0.08s`（沿用，超过 0.1s 会觉得粘）。
