# 素材采集

本目录给**美术 / UI** 使用：这里是要做的素材需求与现有素材的问题清单，按此执行即可。

| 文件 | 用途 |
|---|---|
| **`第二批需求.md`** | ⭐ **当前执行**。第二批要做什么、规格、数量、验收速查；开头有第一批完成情况 |
| `素材需求清单.md` | 第一批（历史留档）。完整的缺口总表与规格要求，第二批仍复用其规格 |
| `素材问题证据.png` | 现有素材的问题可视化证据（行走帧尺寸不统一、角色特征漂移、建筑招牌残字），供对照修改 |

## 从哪里开始看

1. **直接看 `第二批需求.md`**——里面有"给采购/美术的验收速查"（第九节），可直接抄给执行方；
2. 需要更细的规格依据时，回查 `素材需求清单.md` 第九节「规格要求」；
3. **`第二批需求.md` 第九节的第 ⑨ 条请务必逐张执行**：项目已累计发现 4 例 AI 残留伪文字/残渣，
   每张新素材入项目前必须放大检查一遍。
