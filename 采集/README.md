# 素材采集

本目录给**美术 / UI** 使用：这里是要做的素材需求与现有素材的问题清单，按此执行即可。

| 文件 | 用途 |
|---|---|
| `素材需求清单.md` | **主文件**。要做什么素材、规格尺寸、优先级批次、验收标准，全在里面 |
| `素材问题证据.png` | 现有素材的问题可视化证据（行走帧尺寸不统一、角色特征漂移、建筑招牌残字），供对照修改 |

## 从哪里开始看

1. 先看 `素材需求清单.md` 的 **第十节「建议的采购顺序」**——按批次做，不要一次全铺开；
2. 再看 **第九节「规格要求」**——尺寸、透明背景、视角、命名规范，这是验收标准；
3. **第九节末尾的「AI 生成素材必查项」请务必逐张执行**：项目已累计发现 4 例 AI 残留伪文字/残渣，每张新素材入项目前必须放大检查一遍。

## 本轮最优先（第 1 批）

4 个角色的四方向行走帧（统一画布 64×112、脚底同基线）+ 女巫立绘 + 基础音效组。

> 行走帧的规格问题见 `素材问题证据.png` 上半部分：现有 24 帧尺寸从 52×106 到 62×109 不等，
> 且「向上」方向 6 帧角色戴了黄草帽、其余方向没有——重做时请统一规格并锁定角色特征。
